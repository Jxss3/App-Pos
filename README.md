Segundo Proyecto personal en desarrollo

Aplicación POS para restaurantes en desarrollo, creada como proyecto personal con el objetivo de optimizar los flujos de venta, control de inventario y experiencia del usuario frente a las soluciones POS tradicionales.

Tecnologias.
Flutter: front-end.
PostgresSQL: base de datos.
Node.Js: back-end para conectar la base de datos con la app.
